# SpikeZone Volleyball Club Website

## 1. Project Overview

SpikeZone is a volleyball club website designed to provide information about the club, its teams, upcoming events, and membership registration.

**GitHub Repository:** https://github.com/irfanrayyan8/iibgroup1-site

## 2. Team Members

| Member | Contributions |
|---|---|
| Irfan | Home page, Teams page, README and Git workflow |
| Faiz | Events page, Join Us page and pull request reviews |

## 3. Website Features

The website consists of five main pages:

- **Home:** Introduces the club.
- **About:** Provides information about the club.
- **Teams:** Displays the club's volleyball teams.
- **Events:** Shows upcoming volleyball events.
- **Join Us:** Allows visitors to register their interest in joining.

## 4. Technologies Used

- HTML
- CSS
- JavaScript
- PHP / Laravel
- Git and GitHub
- Laravel Herd

## 5. Git Workflow and Merge Conflict

We used feature branches to work on separate website pages. Changes were submitted through pull requests and reviewed before being merged into the protected `main` branch.

During development, both members modified the same parts of a file, resulting in a merge conflict. We discussed the changes, combined the necessary code, resolved the conflict, and continued with the project.
